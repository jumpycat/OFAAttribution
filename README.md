## Project Structure
#### This project utilizes dynamic loading for encoder and decoder architectures. For the necessary implementation files (such as `encoder2.py` and `decoder24_with_graph.py`), please refer to the main repository: [Official Repository](https://github.com/jumpycat/DAIR).

#### Denoiser and Noise Extraction: The noise extraction model in our paper follows the methodology described in:
> **On the Detection of Synthetic Images Generated by Diffusion Models** > *Gragnaniello et al., IEEE, 2023.* > [Paper Link](https://ieeexplore.ieee.org/document/10095167) | [Official Repository](https://github.com/grip-unina/DMimageDetection)

We employ a pre-trained DnCNN to extract the **noise residual** (the difference between the original and denoised image). This residual serves as a "fingerprint" that preserves high-frequency artifacts, which are then analyzed in the frequency domain via a log-magnitude FFT transformation.

- `denoiser.py`: Implementation of the DnCNN architecture and denoiser utilities.
- `train_contrastivev_base_real_noiser_fft_bank.py`: Main training script for contrastive feature extraction using a supervised contrastive loss, memory banks, and FFT-based input transformations.


## Usage

### Training
To start the training process for the feature extractor:
```
python train_contrastivev_base_real_noiser_fft_bank.py --train_dir /path/to/dataset --batch_size 16
```
